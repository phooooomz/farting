# RPG Systems Roadmap

## Prototype implemented
- Movement, collision map
- One Slime enemy
- Attack and counterattack
- EXP and level-up
- Gel drop counter
- Save file (basic binary save)

## Planned next
1. Replace console tile map with sprite/tile graphics using PSP GU or a PSP-friendly 2D library.
2. Add inventory UI and item data table.
3. Add crafting recipes, weapon/armor equipment and stats.
4. Add monster variety, spawn areas and respawn timers.
5. Add town, NPC dialogue, quests, map exits and dungeon.
6. Add Thai UI/font rendering.
7. Investigate PSP adhoc/Wi-Fi multiplayer; MMO-style persistent server will require a separate server and careful compatibility testing.
